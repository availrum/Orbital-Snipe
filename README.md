\# Orbital Snipe



Unreal Engine과 C++로 개발 중인 개인 게임 프로젝트입니다.



여러 천체가 상호작용하는 힘의 장에서 움직이는 목표물을 사격하는 게임을 목표로 합니다.

현재 발사 조건을 기반으로 투사체의 예상 궤적을 실시간으로 표시하며,

향후 수치 적분 방식을 RK4로 개선하고 실제 물리 시뮬레이션과 예측 시스템에 동일한 solver를 적용할 예정입니다.



\## Current Features



\- C++ 기반 중력체 및 중력 계산

\- 복수 중력원에 의한 투사체 운동

\- 대포 조준 및 발사

\- 실시간 발사 예상 궤적 표시

\- Unreal Pawn / GameMode / PlayerController 구성



\## Planned Improvements



\- Physics solver 구조 분리

\- RK4 적분 구현

\- 움직이는 천체를 포함한 미래 궤적 예측

\- 플레이어 ↔ 대포 탑승/하차 개선

\- 충돌 및 점수 시스템

\- Euler / RK4 정확도 및 성능 비교
